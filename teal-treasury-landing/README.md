# teal-treasury-landing — source code

Live demo: https://kedhar-components.pages.dev/#teal-treasury-landing

Folders under components/ are React + TypeScript + Tailwind components.
Main file: components/teal-treasury-landing/teal-treasury-landing.tsx  (usage example: components/teal-treasury-landing/demo.tsx)

Put each folder's .tsx file at src/components/ui/<folder>.tsx in a
